[git-cliff](https://git-cliff.org) from the Conventional Commits that release adds. GitHub's merge
commits are left out, and so are the formatting commits `.git-blame-ignore-revs` lists and any commit
that only edits that list. How a release is cut is in the README's Releasing section.
